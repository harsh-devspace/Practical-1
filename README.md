# Practical 1: Hello React Application

## Objective
To set up the React development environment using Node.js and npm (Vite / Create React App), and develop a simple React application that displays static content using JSX and functional components.

## Topics Covered
- Node.js & npm setup
- React fundamentals & JSX syntax
- Functional components
- Tailwind CSS setup and styling

## Project Structure

├── src/

## Installation & Running Steps
1. Navigate to the project directory:
   ```bash
   cd Practical-1
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`.
